# LineChart

`m3k-line-chart` is a dependency-free, hand-written SVG line chart for plotting one
or more series over a numeric, string, or `Date` x axis. Use it for trends over
time (revenue by month, tickets per week); use `m3k-bar-chart` instead when
comparing discrete categories. The SVG fills the host width and uses the measured
width as its viewBox, so one SVG unit equals one CSS px and labels never stretch.

**Atomic level:** Organism — composed from the pure scale/tick/path helpers in
`internal/scale.ts` and the `injectHostWidth()` ResizeObserver signal; it renders
no child components. Typically projected inside `m3k-chart-card`.

## Usage

```ts
import { Component } from '@angular/core';
import { LineChartComponent, LineChartSeries } from '@m3kit/charts';

@Component({
  selector: 'app-revenue-trend',
  imports: [LineChartComponent],
  template: `
    <m3k-line-chart
      [series]="series"
      [area]="true"
      ariaLabel="Revenue by month"
    />
  `,
})
export class RevenueTrendComponent {
  readonly series: readonly LineChartSeries[] = [
    {
      name: 'Revenue',
      points: [
        { x: 'Jan', y: 4200 },
        { x: 'Feb', y: 5100 },
        { x: 'Mar', y: 4800 },
      ],
    },
  ];
}
```

## Inputs

| Input | Type | Default | Description |
| --- | --- | --- | --- |
| `series` | `readonly LineChartSeries[]` | required | Series to plot. Each point's `x` may be a `number` (used as-is), `Date` (epoch ms), or `string` (positioned by index). A single-point series renders a marker dot instead of a line. |
| `area` | `boolean` | `false` | Fills under each line with a translucent `color-mix()` tint of its series color. |
| `showAxes` | `boolean` | `true` | Renders axis lines and tick labels (off switches to slim 4px margins — a bare sparkline shape). |
| `showGrid` | `boolean` | `true` | Renders hairline horizontal grid lines at the y ticks. |
| `height` | `number` | `240` | Rendered height in px (also the viewBox height). |
| `ariaLabel` | `string` | `'Line chart'` | Short accessible name; rendered as SVG `aria-label` and `<title>`. |
| `ariaDescription` | `string \| null` | `null` | Optional SVG `<desc>` override. Defaults to `lineChartAccessibilitySummary(series).description`; use `chartRowsToText(summary.rows)` for adjacent table fallbacks. |

No outputs.

## Theming

Token-only styling — the component consumes:

| Token | Used for |
| --- | --- |
| `--app-chart-1..6` | Series stroke colors, cycled by series index via `chartSeriesColor(i)` (series 7 wraps to `--app-chart-1`); the `area` fill is a 20% `color-mix()` of the same token. |
| `--app-font-data` | Tick numerals (brand data/mono stack). |
| `--mat-sys-outline-variant` | Hairline grid lines. |
| `--mat-sys-outline` | Axis lines. |
| `--mat-sys-on-surface-variant` | Tick label fill. |

## Do / Don't

- **Do** pass the same series order to `m3k-chart-legend` (`colorIndex` = series index) so legend swatches match line colors.
- **Do** keep a table/text equivalent for decision-making charts; the exported `chart-a11y` helpers are the baseline, dependency-free way to produce it.
- **Don't** style series colors yourself (no `[style.stroke]`, no per-brand CSS) — colors come only from the closed `--app-chart-1..6` contract so every brand reskins the chart for free.
- **Don't** add D3/ECharts just for basic line/area/sparkline needs. Use the documented ADR escape hatch only when pan/zoom, linked brushing, annotations, or data volume exceed the SVG baseline.
