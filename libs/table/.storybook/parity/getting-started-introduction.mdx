# m3kit

m3kit is a clean-room, rethemable **Material 3 UI component library** — an
Angular 19 / Nx 20 reference monorepo of general-purpose UI: data tables,
dashboards, hand-built SVG charts, typed forms, app shells, and a theming
SDK, demonstrated by a synthetic-data reporting demo app.

Source: **[github.com/jpleva91/m3kit](https://github.com/jpleva91/m3kit)**

## The lift-and-own model

m3kit is a **reference to be read and copied, not a dependency to be
installed**. Nothing is published to npm. You source-internalize the
`libs/*` folders into your own workspace and own them outright:

- **No version treadmill.** There is no package to upgrade, no breaking
  release to chase. The code is yours the moment you copy it.
- **No black box.** Every component is small, standalone, signals-first,
  `OnPush`, and strictly typed — built to be read, understood, and edited.
- **No lock-in.** Angular Material is the engine, not the API. The public
  surface is the `m3k-*` component set plus a closed design-token contract.

See `docs/ADOPTION_GUIDE.md` (what to copy, tag remapping, alias renaming)
and `docs/INTERNALIZATION_GUIDE.md` (ownership transfer, license
obligations) in the repository for the full copy-in procedure.

## Why it reskins

Components consume design tokens **only** — Material 3 system tokens
(`var(--mat-sys-*)`) plus a small `--app-*` contract. A brand is a pure
token re-emission, so the entire kit reskins without touching component
code. Twelve brands ship in the repo (Instruments, Terminal, Ledger, Field
Guide, Carbon, Brutalist, Meadow, Beacon, Noir, Pop, Gazette, Synth), each
light + dark — try them with the **Brand** and **Mode** toolbar controls
above.

## Ground rules baked into the code

- **Token-only styling** — no raw hex in components, no per-brand selectors.
- **No chart or UI library dependencies** — charts are hand-written SVG; the
  dependency surface is Angular + Material/CDK + `@ngrx/signals`.
- **Synthetic data only** — customers, orders, invoices, support tickets,
  products, all generated by `@m3kit/testing` factories.
- **Machine-enforced boundaries** — `@nx/enforce-module-boundaries` keeps
  the library graph honest.
